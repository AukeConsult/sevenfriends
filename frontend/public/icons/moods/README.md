# Mood icons

`mood1.svg` to `mood4.svg`: the four moods a person can stick to their profile, so their friends see how they feel
(1 happy, 2 calm, 3 tired, 4 down). Replace a file with a square image of the same name to change it. The names that
are read out and shown on hover are in `frontend/src/app/core/moods.ts`.
