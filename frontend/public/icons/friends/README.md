# Friend icons

`friend1.svg` to `friend7.svg`: one icon for each of the 7 seats on the Friends page (seat 1 uses `friend1.svg`, and so on).
They are shown as the picture of the friend in that seat, and (faded) in an empty seat.

To change one, replace the file with another **square** image of the same name (an SVG is best, a PNG works too if you
also change the extension in `friends.html`). Original drawings, free to change.
